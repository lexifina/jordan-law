# محكمة التمييز الأردنية: قرار جزاء رقم 345/2017 تاريخ 2017-02-28

وحيث ان القرار المطعون فيه صدر بحق المتهم وجاهياً بتاريخ 29/12/2016 والتمييز المقدم بتاريخ 19/1/2017 أي بعد مضي المدة القانونية المنصوص عليها بالمادة 275/1/أ من قانون أصول المحاكمات الجزائية مما يتعين معه رد التمييز شكلاً.
