# محكمة التمييز الأردنية: قرار حقوق رقم 251/2017 تاريخ 2017-03-22

وحيث ان لائحة التمييز لا تحمل توقيع الوكيل فتغدو منعدمة الأثر القانوني لعدم صدورها عن وكيل الطاعنة وعليه فيكون رد التمييز شكلاً موافقاً للقانون.
